Weather API Documentation

URL format: http://127.0.0.1:5000/api/station/date

Get the temperature for one station of a specific date: http://127.0.0.1:5000/api/10/1988-10-25

Get all the temperatures for one station: http://127.0.0.1:5000/api/10

Get all the temperatures for one station of a single year: http://127.0.0.1:5000/api/year/10/1988
